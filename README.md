# Academia Digital

Academia personal de estudio: ocho materias, 31 lecciones iniciales, exámenes de repaso y cuatro retos HTML/CSS. Incluye progreso local y respaldos JSON.

Abre index.html o visita la página de GitHub Pages. Sin dependencias ni servidor de aplicación. index.html contiene la estructura; styles.css, el diseño; data.js, las clases; app.js, la interacción. assets contiene las imágenes.

Esta edición pública excluye libros, entregas, respaldos y enlaces privados. El progreso permanece en el navegador y no se sincroniza entre dispositivos. Gengar pertenece a sus respectivos titulares; proyecto personal no oficial.
